# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-11-19

### Added
- WordPress ingestion (REST API + `publish` webhook mu-plugin).
- XNQC claims registry built from the WooCommerce Store API.
- Claude writer with structured outputs and server-side fallback; offline template writer.
- Compliance engine (rules R1–R6, disclaimer and XNQC auto-fix) and AI legal reviewer.
- Pinterest pin and Facebook card rendering (Be Vietnam Pro).
- Peak-hour scheduler, Graph API v27.0 and Pinterest API v5 publishers, dry-run outbox.
- Editor dashboard: overview, content, review screen, week/month calendar, workflow traces, claims registry, report, audit log.
- Weekly report with AI insights; Telegram notifications.
- n8n workflow (webhook, 15-minute schedule, Monday report).
- Docker Compose, systemd and nginx deployment, GitHub Actions CI.
